## Critical Bugs Found
1. **CORS blocks browser login**: The CORS plugin blocks form POST requests from the browser
   because `http://192.168.0.29:3011` is not in the allowed origins list.
   Default allowed: `['http://localhost:3000', 'http://localhost:5173']`
   Fix: Add server's own origin to CORS_ORIGINS env var or allow same-origin by default.
   File: `src/plugins/index.ts` line 39-54

2. **Dashboard Credits Modal - User list loading fails**: The quick action "充值积分" modal
   fetches `/api/admin/users?limit=50` and expects `res.data` to be an array, but the API
   returns `{success: true, data: {items: [...], total: 1, ...}}`. The code does
   `users = res.data || res.users || []` but `res.data` is an object, not an array.
   Fix: Change to `users = res.data.items || res.data || res.users || []`
