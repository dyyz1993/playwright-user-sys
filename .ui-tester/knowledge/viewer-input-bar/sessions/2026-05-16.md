## Findings
- **Bug 1 (Critical)**: Viewer `connectWebSockets()` creates WS URLs without `?token=` param
  - WS connections immediately close with code 1006 (no auth)
  - Fix: Add token to WS URL from page URL params
  - File: viewer page HTML, `connectWebSockets()` function (line 277-278)

- **Bug 2 (Critical)**: Viewer `sendEvent()` puts data in wrong format
  - Viewer puts x,y directly in event object: `{type, timestamp, x, y}`
  - Server reads from `event.data`: expects `{type, timestamp, data: {x, y}}`
  - Fix: Put all data params inside a `data` sub-object
  - File: viewer page HTML, `sendEvent()` function (line 447-458)

- **Bug 3 (Critical)**: form.field event never reaches viewer
  - Input field gets focused on remote page (blue focus ring visible)
  - But the focusin → exposeFunction → sessionFocusEmitter chain doesn't fire
  - Possible cause: init script not injected after page navigation
  - File: events.handler.ts (line 148-151), browser.service.ts (line 1020-1046)

- **Feature Works When Manual**: The keyboard modal + text sync flow works correctly
  when manually triggered (showKeyboardModal + focusedElement + sendEventFixed)
  - Text successfully synced to remote input field ("Hello from mobile!" appeared)
