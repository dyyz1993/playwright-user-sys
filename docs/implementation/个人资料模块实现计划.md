# 个人资料模块实现计划

## 模块概述

个人资料模块包含 4 个功能点,用于用户管理和个人信息维护。

## 功能列表

| 功能 ID | 功能名称 | 优先级 | 状态 | 说明 |
|---------|----------|--------|------|------|
| P1-P01 | 访问个人资料页面 | P1 | 需验证 | 页面路由已存在 |
| P1-P02 | 修改个人信息 | P1 | 需验证 | API 已存在 |
| P1-P03 | 修改密码 | P1 | 需验证 | API 已存在 |
| P1-P04 | 查看/重置 API 密钥 | P1 | 需验证 | API 已存在 |

## 现有实现分析

### 已实现的 API

1. **GET /api/users/me** - 获取当前用户信息
2. **PUT /api/users/me** - 更新当前用户信息
3. **PUT /api/users/me/password** - 修改当前用户密码
4. **POST /api/users/me/apikey/regenerate** - 重新生成 API Key

### 已实现的前端页面

1. **/admin/profile** - 个人资料页面 (src/views/pages/profile.ejs)
2. 包含个人信息表单、密码修改表单、API Key 管理功能

### 问题分析

根据测试用例分析,可能存在的问题:

1. **API 路由注册**: 需要确认 `/api/users/me` 路由是否正确注册到 Fastify
2. **前端 API 调用**: 需要确认前端调用的端点是否正确
3. **认证中间件**: 需要确认 JWT 验证是否正常工作
4. **错误处理**: 需要确认错误响应是否正确显示

## API 设计文档

### 1. 获取当前用户信息

**端点**: `GET /api/users/me`

**请求头**:
```
Authorization: Bearer <token>
```

**响应格式**:
```json
{
  "success": true,
  "data": {
    "id": 1,
    "username": "admin",
    "email": "admin@example.com",
    "role": "admin",
    "credits": 1000,
    "webhook_url": "https://example.com/webhook",
    "api_key": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "created_at": "2024-01-01T00:00:00.000Z"
  }
}
```

### 2. 更新当前用户信息

**端点**: `PUT /api/users/me`

**请求体**:
```json
{
  "email": "newemail@example.com",
  "webhook_url": "https://example.com/new-webhook"
}
```

**响应格式**:
```json
{
  "success": true,
  "data": {
    "id": 1,
    "username": "admin",
    "email": "newemail@example.com",
    "role": "admin",
    "credits": 1000,
    "webhook_url": "https://example.com/new-webhook",
    "api_key": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "created_at": "2024-01-01T00:00:00.000Z"
  }
}
```

### 3. 修改当前用户密码

**端点**: `PUT /api/users/me/password`

**请求体**:
```json
{
  "current_password": "oldpassword123",
  "new_password": "newpassword456"
}
```

**响应格式**:
```json
{
  "success": true,
  "data": {
    "message": "密码修改成功"
  }
}
```

**错误响应**:
```json
{
  "success": false,
  "error": "当前密码错误"
}
```

### 4. 重新生成 API Key

**端点**: `POST /api/users/me/apikey/regenerate`

**请求头**:
```
Authorization: Bearer <token>
```

**响应格式**:
```json
{
  "success": true,
  "data": {
    "api_key": "new-api-key-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
  }
}
```

## 测试方案

### 1. API 单元测试

**文件**: `tests/api/user-profile.test.ts`

```typescript
import { test, expect } from '@playwright/test';

const BASE_URL = process.env.BASE_URL || 'http://localhost:3000';
const TOKEN = 'your-test-token';

test.describe('个人资料 API', () => {
  test('GET /api/users/me - 获取当前用户信息', async ({ request }) => {
    const response = await request.get(`${BASE_URL}/api/users/me`, {
      headers: { Authorization: `Bearer ${TOKEN}` }
    });
    expect(response.status()).toBe(200);
    const data = await response.json();
    expect(data.success).toBe(true);
    expect(data.data).toHaveProperty('username');
  });

  test('PUT /api/users/me - 更新用户信息', async ({ request }) => {
    const response = await request.put(`${BASE_URL}/api/users/me`, {
      headers: { Authorization: `Bearer ${TOKEN}` },
      data: { email: 'test@example.com' }
    });
    expect(response.status()).toBe(200);
    const data = await response.json();
    expect(data.success).toBe(true);
  });

  test('PUT /api/users/me/password - 修改密码', async ({ request }) => {
    const response = await request.put(`${BASE_URL}/api/users/me/password`, {
      headers: { Authorization: `Bearer ${TOKEN}` },
      data: { current_password: 'old', new_password: 'new' }
    });
    expect(response.status()).toBe(200);
  });

  test('POST /api/users/me/apikey/regenerate - 重新生成 API Key', async ({ request }) => {
    const response = await request.post(`${BASE_URL}/api/users/me/apikey/regenerate`, {
      headers: { Authorization: `Bearer ${TOKEN}` }
    });
    expect(response.status()).toBe(200);
    const data = await response.json();
    expect(data.data).toHaveProperty('api_key');
  });
});
```
