# P0 核心功能 UI 自动化测试执行指南

## 测试概述

本测试套件包含 **40 个 P0 级别的核心功能测试用例**，覆盖管理后台最关键的功能。

### 测试覆盖范围

| 模块 | 测试用例数 | 测试ID前缀 | 预计执行时间 |
|------|-----------|-----------|-------------|
| 登录认证流程 | 8个 | P0-L | ~5分钟 |
| 用户管理CRUD | 12个 | P0-U | ~10分钟 |
| 会话管理 | 8个 | P0-S | ~8分钟 |
| 机器管理 | 8个 | P0-M | ~8分钟 |
| 权限控制 | 4个 | P0-A | ~4分钟 |
| **总计** | **40个** | - | **~35分钟** |

## 环境准备

### 1. 安装依赖

```bash
pnpm add -D @playwright/test
```

### 2. 安装浏览器（首次运行）

```bash
npx playwright install chromium
```

注意：本配置使用本地 Chromium，路径为 `/Applications/Chromium.app/Contents/MacOS/Chromium`

### 3. 启动开发服务器

```bash
# 在终端1启动服务器
pnpm dev
```

确保服务器运行在 `http://localhost:3000`

## 执行测试

### 方式1: 执行所有 P0 测试

```bash
# 在终端2执行
npx playwright test tests/e2e/p0-critical.spec.ts
```

### 方式2: 执行特定模块

```bash
# 只执行登录认证测试
npx playwright test tests/e2e/p0-critical.spec.ts --grep "P0-登录"

# 只执行用户管理测试
npx playwright test tests/e2e/p0-critical.spec.ts --grep "P0-用户"

# 只执行会话管理测试
npx playwright test tests/e2e/p0-critical.spec.ts --grep "P0-会话"

# 只执行机器管理测试
npx playwright test tests/e2e/p0-critical.spec.ts --grep "P0-机器"

# 只执行权限控制测试
npx playwright test tests/e2e/p0-critical.spec.ts --grep "P0-权限"
```

### 方式3: 执行单个测试用例

```bash
# 执行特定的测试
npx playwright test tests/e2e/p0-critical.spec.ts --grep "P0-L01"

# 执行多个特定测试
npx playwright test tests/e2e/p0-critical.spec.ts --grep "P0-L01|P0-L02|P0-L03"
```

### 方式4: 调试模式

```bash
# 调试模式（带UI，可以逐步执行）
npx playwright test tests/e2e/p0-critical.spec.ts --debug

# 显示浏览器窗口运行
npx playwright test tests/e2e/p0-critical.spec.ts --headed
```

### 方式5: 生成测试报告

```bash
# 执行测试并生成HTML报告
npx playwright test tests/e2e/p0-critical.spec.ts --reporter=html

# 查看报告
npx playwright show-report
```

测试执行时会在控制台显示实时进度：


### 2. HTML 报告

执行后自动生成 HTML 报告：

```bash
# 查看报告
open playwright-report/index.html
```

或使用命令：

```bash
npx playwright show-report
```

### 3. JSON 报告

生成 `test-results.json`，可用于 CI/CD 集成。

### 4. 失败截图和视频

测试失败时会自动保存：
- 截图：`test-results/[测试名称]/`
- 视频：`test-results/[测试名称]/`
- 追踪：`test-results/[测试-name]/trace.zip`

## 常见问题

### Q1: 测试失败，提示找不到元素

**原因**: 页面结构发生变化或元素定位器不准确

**解决**:
1. 使用 `--headed` 参数运行，查看实际页面
2. 检查页面加载是否完成
3. 更新元素定位器

### Q2: 测试超时

**原因**: 网络慢或服务器响应慢

**解决**:
1. 增加超时时间
2. 检查开发服务器是否正常运行
3. 查看浏览器控制台是否有JavaScript错误

### Q3: 登录失败

**原因**: 测试账号不存在或密码错误

**解决**:
1. 确认管理员账号存在（用户名: admin, 密码: REDACTED_ADMIN_PASS）
2. 检查数据库连接是否正常
3. 手动测试登录功能是否正常

## CI/CD 集成

### GitHub Actions 示例

```yaml
name: E2E Tests

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v3

      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: 18

      - name: Install dependencies
        run: pnpm install

      - name: Install Playwright
        run: npx playwright install --with-deps chromium

      - name: Start development server
        run: pnpm dev &
          sleep 10

      - name: Run P0 tests
        run: npx playwright test tests/e2e/p0-critical.spec.ts

      - name: Upload test report
        if: always()
        uses: actions/upload-artifact@v3
        with:
          name: playwright-report
          path: playwright-report/
```
