## 🏗️ 系统架构说明

### 三端架构

```
┌─────────────────────────────────────────────────────────────────┐
│                         N个客户端 (Client SDK)                    │
│                   HTTP请求 + WebSocket连接                        │
└───────────────────────────┬─────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│                    管理端服务器 (Manager Server)                  │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ Fastify HTTP API (Port: 3000)                            │  │
│  │ - 用户认证 (JWT)                                          │  │
│  │ - 会话管理 API                                            │  │
│  │ - 机器管理 API                                            │  │
│  │ - WebSocket 代理服务                                      │  │
│  └──────────────────────────────────────────────────────────┘  │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ gRPC Server (Port: 50051)                                │  │
│  │ - 机器注册服务                                            │  │
│  │ - 双向流通信 (Connect)                                    │  │
│  │ - 浏览器启动/关闭 (LaunchBrowser/CloseBrowser)            │  │
│  │ - 机器状态查询 (GetMachineStatus)                         │  │
│  └──────────────────────────────────────────────────────────┘  │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ MySQL 数据库                                              │  │
│  │ - users (用户表)                                          │  │
│  │ - sessions (会话表)                                       │  │
│  │ - machines (机器表)                                       │  │
│  │ - credit_history (积分历史表)                             │  │
│  └──────────────────────────────────────────────────────────┘  │
└───────────────────────────┬─────────────────────────────────────┘
                            │ gRPC通信
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│              N个机器端服务 (Machine Service)                      │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ gRPC Client (连接管理端)                                  │  │
│  │ - 机器注册 (Register)                                     │  │
│  │ - 心跳上报 (Heartbeat)                                    │  │
│  │ - 会话状态上报 (SessionStatus)                            │  │
│  └──────────────────────────────────────────────────────────┘  │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ Chrome实例管理 (Puppeteer)                                │  │
│  │ - 启动浏览器实例                                          │  │
│  │ - WebSocket代理 (Port: 8082+)                             │  │
│  │ - 截图和视频流                                            │  │
│  │ - 文件上传处理                                            │  │
│  └──────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
```

### 关键技术栈

| 层级 | 技术栈 | 说明 |
|-----|--------|------|
| 客户端 | Node.js + SDK | HTTP API调用 + WebSocket连接 |
| 管理端 | Fastify + gRPC + MySQL | HTTP API服务 + gRPC服务器 |
| 机器端 | Node.js + Puppeteer + gRPC | Chrome实例管理 + gRPC客户端 |
