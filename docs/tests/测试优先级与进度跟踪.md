## 一、测试优先级定义

### 1.1 优先级分级标准

| 优先级 | 定义 | 测试要求 | 发布阻塞 |
|-------|------|---------|---------|
| **P0** | 核心功能，系统必须具备的能力 | 100%覆盖率，必须全部通过 | 是 |
| **P1** | 重要功能，影响用户体验的主要功能 | ≥90%覆盖率 | 部分阻塞 |
| **P2** | 辅助功能，锦上添花的功能 | ≥70%覆盖率 | 否 |

### 1.2 优先级判定矩阵

| 影响范围 × 使用频率 | 高频使用 | 中频使用 | 低频使用 |
|--------------|--------|--------|--------|
| **影响所有用户** | P0 | P0 | P1 |
| **影响部分用户** | P0 | P1 | P2 |
| **影响单个用户** | P1 | P2 | P2 |
