# 集成测试数据库初始化指南

## 问题

测试数据库 `playwright_test_user_sys` 已创建，但缺少表结构，导致测试失败：

```
Error: Table 'playwright_test_user_sys.users' doesn't exist
```

## 解决方案

### 方案 1: 复制现有数据库表结构（推荐）

从现有数据库复制表结构和数据到测试数据库：

```bash
# 1. 导出现有数据库结构
mysqldump -h REDACTED_INTERNAL_HOST -uroot -pREDACTED_PASSWORD \
  --no-data playwright_user_sys > /tmp/schema.sql

# 2. 在测试数据库中创建表结构
mysql -h REDACTED_INTERNAL_HOST -uroot -pREDACTED_PASSWORD \
  playwright_test_user_sys < /tmp/schema.sql

# 3. 验证表创建成功
mysql -h REDACTED_INTERNAL_HOST -uroot -pREDACTED_PASSWORD \
  -e "USE playwright_test_user_sys; SHOW TABLES;"
```

### 方案 2: 运行数据库迁移

如果项目有迁移脚本：

```bash
# 查找迁移文件
ls -la migrations/ || ls -la src/migrations/

# 运行迁移到测试数据库
NODE_ENV=test DB_NAME=playwright_test_user_sys \
  npx tsx src/migrate.ts

# 或使用项目命令
NODE_ENV=test pnpm migrate
```

### 方案 3: 手动执行建表 SQL

如果项目有初始化 SQL 文件：

```bash
# 查找 SQL 文件
find . -name "*.sql" -type f

# 执行到测试数据库
mysql -h REDACTED_INTERNAL_HOST -uroot -pREDACTED_PASSWORD \
  playwright_test_user_sys < /path/to/schema.sql
```

## 验证步骤

执行完上述任一方案后，验证：

```bash
# 1. 检查表是否创建
mysql -h REDACTED_INTERNAL_HOST -uroot -pREDACTED_PASSWORD \
  -e "USE playwright_test_user_sys; SHOW TABLES;"

# 应该看到：
# users
# sessions
# machines
# credit_history
# operation_logs
# request_logs
# webhook_events

# 2. 检查表结构

  -e "USE playwright_test_user_sys; DESCRIBE users;"

# 3. 运行测试验证
pnpm test:routes
```

## 自动化脚本

创建一个初始化脚本 `scripts/init-test-db.sh`：

```bash
#!/bin/bash
set -e

echo "🔧 初始化测试数据库..."

# 配置
DB_HOST="REDACTED_INTERNAL_HOST"
DB_USER="root"
DB_PASS="REDACTED_PASSWORD"
SOURCE_DB="playwright_user_sys"
TEST_DB="playwright_test_user_sys"

# 1. 导出表结构
echo "📦 导出表结构..."
mysqldump -h $DB_HOST -u$DB_USER -p$DB_PASS \
  --no-data $SOURCE_DB > /tmp/test-schema.sql

# 2. 创建测试数据库（如果不存在）
echo "🏗️  创建测试数据库..."
mysql -h $DB_HOST -u$DB_USER -p$DB_PASS \
  -e "CREATE DATABASE IF NOT EXISTS $TEST_DB CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 3. 导入表结构
echo "📥 导入表结构..."
mysql -h $DB_HOST -u$DB_USER -p$DB_PASS \
  $TEST_DB < /tmp/test-schema.sql

# 4. 验证
echo "✅ 验证表结构..."
TABLES=$(mysql -h $DB_HOST -u$DB_USER -p$DB_PASS \
  -e "SELECT COUNT(*) AS count FROM information_schema.tables WHERE table_schema = '$TEST_DB';" \
  --skip-column-names)

echo "📊 测试数据库包含 $TABLES 张表"

# 5. 清理临时文件
rm -f /tmp/test-schema.sql

echo "✨ 测试数据库初始化完成！"
```

使用方式：

```bash
chmod +x scripts/init-test-db.sh
./scripts/init-test-db.sh
```

## 常见问题

### Q: 每次测试都要重新初始化吗？

A: 不需要。表结构创建一次即可，测试数据会在每次测试前后通过 `clearAllTables()` 清空。

### Q: 如何重置测试数据库？

A:

```bash
# 删除所有数据
mysql -h REDACTED_INTERNAL_HOST -uroot -pREDACTED_PASSWORD \
  -e "USE playwright_test_user_sys;
     DELETE FROM users;
     DELETE FROM sessions;
     DELETE FROM machines;
     DELETE FROM credit_history;
     DELETE FROM operation_logs;
     DELETE FROM request_logs;
     DELETE FROM webhook_events;"

# 或重新运行初始化脚本
./scripts/init-test-db.sh
```

### Q: 表结构变更后如何更新？

A: 当生产数据库表结构变更时，需要同步更新测试数据库：

```bash
# 重新导出并导入表结构
mysqldump -h REDACTED_INTERNAL_HOST -uroot -pREDACTED_PASSWORD \
  --no-data playwright_user_sys > /tmp/schema.sql
mysql -h REDACTED_INTERNAL_HOST -uroot -pREDACTED_PASSWORD \
  playwright_test_user_sys < /tmp/schema.sql
```
