## 四、权限控制分析

### 4.1 当前权限体系

| 角色 | 登录 | 仪表盘 | 用户管理 | 会话管理 | 机器管理 | 操作日志 | 系统设置 | 个人资料 | 文件上传 |
|-----|------|--------|---------|---------|---------|---------|---------|---------|---------|
| 管理员 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| 普通用户 | ✅ | ✅ | ❌ | ✅ | ❌ | ❌ | ✅ | ✅ | ❌ |

### 4.2 权限验证方式

- **路由级验证**: `fastify.verifyJWT` 中间件
- **页面级验证**: `request.user?.role !== 'admin'` 检查
- **API级验证**: `preHandler: [authenticate]` 中间件

## 五、技术实现要点

### 5.1 前端技术栈

- **模板引擎**: EJS
- **CSS框架**: Tailwind CSS (通过 CDN)
- **图标库**: Font Awesome (通过 CDN)
- **图表库**: Chart.js (机器详情页)
- **HTTP请求**: Fetch API

### 5.2 后端技术栈

- **Web框架**: Fastify
- **认证**: JWT (Cookie 存储)
- **密码加密**: SHA256
- **数据库**: Knex.js + SQLite/MySQL
- **文件上传**: Multipart Form Data

## 六、数据模型关系

```
User (用户)
  ├── id, username, email, password
  ├── role (admin/user)
  ├── status (active/inactive)
  ├── credits (算力点数)
  ├── api_key (API密钥)
  ├── webhook_url (Webhook URL)
  └── created_at

Session (会话)
  ├── id, user_id, machine_id
  ├── status (created/connected/disconnected/closed)
  ├── port (WebSocket端口)
  ├── credits_used (消耗点数)
  ├── options (会话选项JSON)
  ├── error_message (错误信息)
  ├── screenshot_url (截图URL)
  └── created_at, start_time, end_time

Machine (机器)
  ├── id, name, ip_address
  ├── grpc_port (gRPC端口)
  ├── status (online/offline)
  ├── max_sessions (最大会话数)
  ├── active_sessions (活跃会话数)
  ├── load (负载百分比)
  ├── cpu_usage, memory_usage, disk_usage
  └── last_heartbeat

OperationLog (操作日志)
  ├── id, admin_id, target_user_id
  ├── action (操作类型)
  ├── details (详情JSON)
  ├── ip_address
  └── created_at
```
