## 测试架构概述

### 核心理念

集成测试采用 **真实环境 + 真实数据** 的方式：

```
┌─────────────────────────────────────────────────────┐
│                  测试用例                            │
│  - 准备数据 (Factories)                             │
│  - 调用路由 (app.inject)                            │
│  - 验证结果 (HTTP + Database)                        │
└─────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────┐
│                 Fastify 应用                         │
│  - 真实路由 (Routes)                                 │
│  - 真实中间件 (Middleware)                           │
│  - 真实控制器 (Controllers)                          │
└─────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────┐
│              MySQL 测试数据库                        │
│  - 真实数据库操作                                     │
│  - 每次测试清空重置                                   │
└─────────────────────────────────────────────────────┘
```

### 关键特性

| 特性 | 说明 |
|------|------|
| **真实 HTTP** | 使用 `app.inject()` 发送真实请求 |
| **真实数据库** | 连接 MySQL 测试数据库，执行真实 SQL |
| **真实中间件** | JWT 认证、权限验证等都真实执行 |
| **Mock 外部** | 仅 Mock 外部服务（如 webhook） |
| **数据隔离** | 每个测试前后清空数据库 |

## 环境准备

### 1. 创建测试数据库

使用 root 用户（密码为 root）创建测试数据库：

```bash
# 连接到 MySQL
mysql -h REDACTED_INTERNAL_HOST -uroot -proot

# 执行以下 SQL
CREATE DATABASE IF NOT EXISTS playwright_test_user_sys CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 创建测试数据库用户（可选，也可以用 root）
CREATE USER IF NOT EXISTS 'test_user'@'%' IDENTIFIED BY 'test_password';
GRANT ALL PRIVILEGES ON playwright_test_user_sys.* TO 'test_user'@'%';
FLUSH PRIVILEGES;

# 验证数据库创建成功
SHOW DATABASES LIKE 'playwright_test%';
```

### 2. 配置环境变量

在项目根目录创建 `.env.test` 文件：

```bash
# .env.test

NODE_ENV=test
DB_TYPE=mysql
DB_HOST=REDACTED_INTERNAL_HOST
DB_PORT=3306
DB_USER=root
DB_PASSWORD=root
DB_NAME=playwright_test_user_sys

# JWT 配置
JWT_SECRET=test_secret_key_for_testing_only
JWT_EXPIRES_IN=24h

# 其他配置
PORT=3000
LOG_LEVEL=error
```

### 3. 更新测试配置

确保 `src/tests/setup.ts` 正确配置：

```typescript
// src/tests/setup.ts

process.env.NODE_ENV = 'test';
process.env.DB_TYPE = 'mysql';

// 如果需要，可以覆盖数据库配置
if (!process.env.DB_NAME) {
  process.env.DB_NAME = 'playwright_test_user_sys';
}
```

## 编写测试用例

### 基础模板

```typescript
import { describe, it, expect, beforeAll, afterAll } from 'vitest';
import { FastifyInstance } from 'fastify';
import { build } from '../../helpers/app.js';
import { UserModel } from '../../../models/user.model.js';
import { clearAllTables } from '../../helpers/database.js';
import { createTestUser, createTestAdmin } from '../../helpers/factories.js';
import { generateToken } from '../../../utils/auth.js';

describe('功能模块名称', () => {
  let app: FastifyInstance;
  let testUser: any;
  let testAdmin: any;
  let userToken: string;
  let adminToken: string;

  // ========================================
  // 测试初始化
  // ========================================
  beforeAll(async () => {
    // 1. 清空测试数据
    await clearAllTables();

    // 2. 构建应用实例
    app = await build();

    // 3. 创建测试用户
    testUser = await createTestUser({
      username: 'testuser',
      credits: 100,
    });

    // 4. 生成 JWT token
    userToken = generateToken({
      id: testUser.id,
      username: testUser.username,
      role: testUser.role,
    });

    // 5. 创建测试管理员（如果需要）
    testAdmin = await createTestAdmin();
    adminToken = generateToken({
      id: testAdmin.id,
      username: testAdmin.username,
      role: testAdmin.role,
    });
  });

  // ========================================
  // 测试清理
  // ========================================
  afterAll(async () => {
    await clearAllTables();
    await app.close();
  });

  // ========================================
  // 测试用例
  // ========================================
  describe('GET /api/endpoint', () => {
    it('应该成功获取数据', async () => {
      // 1. 准备请求数据
      const params = { /* ... */ };

      // 2. 发送请求
      const response = await app.inject({
        method: 'GET',
        url: '/api/endpoint',
        headers: {
          Authorization: `Bearer ${userToken}`,
        },
        query: params,
      });

      // 3. 验证 HTTP 响应
      expect(response.statusCode).toBe(200);
      const result = JSON.parse(response.payload);
      expect(result.success).toBe(true);
      expect(result.data).toBeDefined();

      // 4. 可选：验证数据库状态
      const dbRecord = await UserModel.findById(testUser.id);
      expect(dbRecord).toMatchObject({
        id: testUser.id,
        username: testUser.username,
      });
    });

    it('未认证应该返回 401', async () => {
      const response = await app.inject({
        method: 'GET',
        url: '/api/endpoint',
        // 不传 Authorization header
      });

      expect(response.statusCode).toBe(401);
    });

    it('权限不足应该返回 403', async () => {
      const response = await app.inject({
        method: 'GET',
        url: '/api/admin/endpoint',  // 需要管理员权限
        headers: {
          Authorization: `Bearer ${userToken}`,  // 普通用户 token
        },
      });

      expect(response.statusCode).toBe(403);
    });
  });

  describe('POST /api/endpoint', () => {
    it('应该成功创建数据', async () => {
      const payload = {
        username: `newuser_${Date.now()}`,
        email: `newuser_${Date.now()}@test.com`,
        password: 'password123',
      };

      const response = await app.inject({
        method: 'POST',
        url: '/api/endpoint',
        headers: {
          Authorization: `Bearer ${adminToken}`,
        },
        payload,
      });

      expect(response.statusCode).toBe(201);
      const result = JSON.parse(response.payload);

      expect(result.success).toBe(true);
      expect(result.data).toHaveProperty('id');
      expect(result.data).toHaveProperty('username', payload.username);

      // 敏感字段不应返回
      expect(result.data).not.toHaveProperty('password');
    });

    it('参数验证失败应该返回 400', async () => {
      const invalidPayload = {
        username: '',  // 空用户名
        email: 'invalid-email',  // 无效邮箱
      };

      const response = await app.inject({
        method: 'POST',
        url: '/api/endpoint',
        headers: {
          Authorization: `Bearer ${adminToken}`,
        },
        payload: invalidPayload,
      });

      expect(response.statusCode).toBe(400);
      const result = JSON.parse(response.payload);
      expect(result.success).toBe(false);
    });
  });
});
```

### 数据库验证

```typescript
it('应该正确更新数据库', async () => {
  // 执行操作
  await app.inject({
    method: 'POST',
    url: `/api/users/${testUser.id}/credits`,
    headers: { Authorization: `Bearer ${adminToken}` },
    payload: { amount: 50 },
  });

  // 验证数据库状态
  const updatedUser = await UserModel.findById(testUser.id);
  expect(updatedUser.credits).toBe(150); // 100 + 50

  // 验证积分历史记录
  const { CreditHistoryModel } = await import('../../../models/credit-history.model.js');
  const history = await CreditHistoryModel.findByUserId(testUser.id);
  expect(history).toHaveLength(1);
  expect(history[0]).toMatchObject({
    user_id: testUser.id,
    amount: 50,
    action: 'grant',
  });
});
```

## 运行测试

### 运行所有测试

```bash
# 运行所有测试
pnpm test

# 或使用 vitest
npx vitest run

# 监听模式
pnpm test:watch
```

### 运行特定类型测试

```bash
# 单元测试
pnpm test:unit

# 模型测试
pnpm test:model:user

# 路由集成测试
pnpm test:routes

# 控制器测试
pnpm test:controllers
```

### 运行单个测试文件

```bash
# 运行特定测试文件
npx vitest run src/tests/integration/routes/user.routes.test.ts

# 运行并监听
npx vitest src/tests/integration/routes/user.routes.test.ts
```

### 调试测试

```bash
# 显示详细输出
npx vitest run --reporter=verbose

# 运行特定测试用例
npx vitest run -t "应该成功获取数据"

# UI 模式（需要安装 @vitest/ui）
npx vitest --ui
```

## 最佳实践

### 1. 测试命名规范

```typescript
// ✅ 好的命名
describe('用户管理', () => {
  it('应该成功创建用户', async () => { });
  it('重复用户名应该返回 400', async () => { });
  it('未认证应该返回 401', async () => { });
});

// ❌ 不好的命名
describe('测试1', () => {
  it('测试创建', async () => { });
});
```

### 2. 数据隔离

```typescript
// ✅ 使用时间戳避免冲突
const username = `user_${Date.now()}`;

// ❌ 固定值可能冲突
const username = 'test_user';
```

### 3. 测试独立性

```typescript
// ✅ 每个测试独立
it('测试A', async () => {
  const user = await createTestUser();
  // 测试逻辑...
});

it('测试B', async () => {
  const user = await createTestUser();  // 创建新用户
  // 测试逻辑...
});

// ❌ 依赖其他测试
it('测试A', async () => {
  global.user = await createTestUser();
});

it('测试B', async () => {
  // 依赖 global.user
});
```

### 4. 完整验证

```typescript
// ✅ 多层验证
it('应该正确处理请求', async () => {
  // 1. 验证 HTTP 状态码
  expect(response.statusCode).toBe(200);

  // 2. 验证响应结构
  const result = JSON.parse(response.payload);
  expect(result).toMatchObject({
    success: true,
    data: expect.any(Object),
  });

  // 3. 验证业务逻辑
  expect(result.data.id).toBeDefined();
  expect(result.data.username).toBe(payload.username);

  // 4. 验证数据库状态
  const dbRecord = await UserModel.findById(result.data.id);
  expect(dbRecord).toBeTruthy();
});

// ❌ 只验证状态码
expect(response.statusCode).toBe(200);
```

### 5. 清理资源

```typescript
// ✅ 正确清理
afterAll(async () => {
  await clearAllTables();
  await app.close();
});

// ❌ 忘记清理
afterAll(async () => {
  // 没有清理，会影响后续测试
});
```

### 6. 有意义的断言消息

```typescript
// ✅ 带消息的断言
expect(response.statusCode).toBe(200, '应该返回 200 OK');

// ❌ 无消息
expect(response.statusCode).toBe(200);
```

## 常见问题

### Q: 测试运行很慢怎么办？

```bash
# 只运行相关测试
npx vitest run -t "用户管理"

# 并行运行（如果测试独立）
# 在 vitest.config.ts 中设置
fileParallelism: true  # 但要注意数据隔离
```

### Q: 数据库连接失败？

```bash
# 检查测试数据库是否创建
mysql -h REDACTED_INTERNAL_HOST -uroot -proot -e "SHOW DATABASES LIKE 'playwright_test%'"

# 检查 .env.test 配置
cat .env.test | grep DB_
```

### Q: 如何测试需要登录的接口？

```typescript
// 使用工厂函数创建用户和 token
const user = await createTestUser();
const token = generateToken(user);

// 在请求中携带 token
const response = await app.inject({
  url: '/api/protected',
  headers: { Authorization: `Bearer ${token}` },
});
```

### Q: 如何测试文件上传？

```typescript
import fs from 'fs';
import path from 'path';

it('应该成功上传文件', async () => {
  const fileBuffer = fs.readFileSync(path.join(__dirname, 'fixtures/test.pdf'));

  const response = await app.inject({
    method: 'POST',
    url: '/api/files/upload',
    headers: {
      Authorization: `Bearer ${userToken}`,
      'Content-Type': 'multipart/form-data',
    },
    payload: fileBuffer,
    // 可能需要特殊处理 multipart
  });

  expect(response.statusCode).toBe(200);
});
```
