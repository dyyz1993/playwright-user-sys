## 📋 各模块详细分析

### 1. 会话管理模块

**报告**: `docs/tests/session-api-analysis.md`

#### 核心字段 (13个)

| 字段 | 类型 | 说明 | 测试重点 |
|------|------|------|----------|
| `id` | number | 主键 | 参数验证 |
| `user_id` | number | 用户ID | 外键关联 |
| `machine_id` | string | 机器ID | 外键关联 |
| `port` | number | 端口号 | 范围验证 |
| `status` | enum | 状态 | 6种状态转换 |
| `options` | json | 配置选项 | JSON验证 |
| `credits_used` | number | 消耗积分 | 计算准确性 |
| `start_time` | Date | 开始时间 | 时区处理 |
| `end_time` | Date\|null | 结束时间 | 可为空 |
| `last_heartbeat` | Date\|null | 最后心跳 | 超时检测 |
| `error_message` | string\|null | 错误信息 | 异常处理 |
| `created_at` | Date | 创建时间 | 自动生成 |
| `updated_at` | Date | 更新时间 | 自动更新 |

#### API 端点 (14个)

```
用户端 API:
├── POST   /api/sessions              - 创建会话
├── GET    /api/sessions/:id          - 获取会话详情
├── GET    /api/sessions              - 获取用户会话列表
├── DELETE /api/sessions/:id          - 释放会话
└── POST   /api/sessions/:id/heartbeat - 心跳检测

管理后台 API:
├── GET    /api/admin/sessions        - 会话列表（筛选、分页）
├── GET    /api/admin/sessions/:id    - 会话详情
├── DELETE /api/admin/sessions/:id    - 强制结束会话
├── POST   /api/admin/sessions/batch-close - 批量结束
└── GET    /api/admin/session/stats   - 会话统计

相关 API:
├── POST   /api/admin/users/:id/sessions - 查看用户会话
├── GET    /api/admin/machines/:id/sessions - 查看机器会话
├── POST   /api/admin/users/batch-recharge - 批量充值
└── POST   /api/admin/sessions/:id/credits - 会话积分操作
```

#### 测试用例分类

| 类别 | 数量 | 说明 |
|------|------|------|
| 字段验证测试 | 67 | 覆盖所有13个字段 |
| API端点测试 | 97 | 覆盖所有14个端点 |
| 业务逻辑测试 | 24 | 状态转换、点数计算、并发 |

#### 重点测试场景

**P0 级别（关键）**:
1. ✅ 点数计算准确性
2. ✅ 状态转换完整性
3. ✅ 权限控制（用户只能访问自己的会话）
4. ✅ 并发创建会话
5. ✅ 重复释放不重复扣费

**P1 级别（重要）**:
1. 筛选和排序功能
2. 批量操作
3. 超时检测
4. 错误处理
