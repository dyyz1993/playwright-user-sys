## 用户初始化机制

### 启动时的初始化流程

系统在启动时会自动执行以下初始化步骤（在 `src/models/migrations.ts` 中实现）：

1. **数据库表创建**：自动创建所有必需的数据库表（users, machines, sessions 等）
2. **管理员账号初始化**：检测并创建默认管理员账号

### 管理员账号创建逻辑

管理员账号创建位于 `src/models/migrations.ts` 的 `initAdminUser()` 函数：

```typescript
export async function initAdminUser() {
  const adminExists = await db('users')
    .where({ role: UserRole.ADMIN })
    .first();

  if (!adminExists) {
    const hashedPassword = await hashPassword(env.ADMIN_PASSWORD);

    await db('users').insert({
      username: env.ADMIN_USERNAME,
      password: hashedPassword,
      role: UserRole.ADMIN,
      status: UserStatus.ACTIVE,
      credits: 9999999, // 管理员无限点数
      created_at: new Date(),
      updated_at: new Date(),
    });

    console.log(`✅ 管理员账号 ${env.ADMIN_USERNAME} 创建成功`);
  }
}
```

**重要特性**：
- 仅在数据库中不存在管理员账号时才创建
- 不会覆盖已存在的管理员账号
- 不会自动修改已存在管理员的密码

### 环境变量配置

管理员账号通过以下环境变量配置（在 `.env` 文件中）：

```bash
# 管理员初始账号
ADMIN_USERNAME=admin
ADMIN_PASSWORD=REDACTED_ADMIN_PASS
```

**默认值**（在 `src/config/env.ts` 中定义）：
- `ADMIN_USERNAME`: `admin`
- `ADMIN_PASSWORD`: `REDACTED_ADMIN_PASS`

## 认证流程说明

### 密码加密机制

系统使用 **SHA256 哈希算法**进行密码加密（在 `src/utils/auth.ts` 中实现）：

```typescript
export async function hashPassword(password: string): Promise<string> {
  return createHash('sha256').update(password).digest('hex');
}

export async function comparePassword(password: string, hashedPassword: string): Promise<boolean> {
  const hashed = await hashPassword(password);
  return hashed === hashedPassword;
}
```

**密码哈希示例**：
- 原密码：`REDACTED_ADMIN_PASS`
- SHA256 哈希：`240be518fabd2724ddb6f04eeb1da5967448d7e831c08c8fa822809f74c720a9`

### 登录接口

系统提供两个登录接口：

#### 1. Web 管理后台登录（`/admin/login`）

**路径**: `POST /admin/login`

**实现位置**: `src/routes/admin.routes.ts`

**认证方式**:
- **当前实现**: 使用 `bcryptjs` 进行密码比较
- **密码存储**: 使用 SHA256 哈希

**⚠️ 已知问题**: 存在密码加密方法不匹配的问题，详见[登录问题排查](#登录问题排查)章节。

#### 2. API 登录接口（`/api/auth/login`）

**路径**: `POST /api/auth/login`

**实现位置**: `src/controllers/auth.controller.ts`

**认证方式**:
- 使用 `comparePassword()` 函数（SHA256）
- 返回 JWT Token

**请求格式**:
```json
{
  "username": "admin",
  "password": "REDACTED_ADMIN_PASS"
}
```

**响应格式**:
```json
{
  "success": true,
  "data": {
    "user": {
      "id": 1,
      "username": "admin",
      "email": null,
      "role": "admin",
      "status": "active",
      "credits": 9999999
    },
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
```

### 用户注册

**当前状态**: 系统不提供公开的用户注册接口。

用户只能通过以下方式创建：
1. 管理员通过 Web 管理后台创建
2. 管理员通过 API 创建（需要管理员权限）
3. 使用脚本创建（如 `pnpm create-test-user`）

## 登录问题排查

### 问题 1: 无法登录到 Web 管理后台

**症状**: 在 `/admin/login` 页面输入正确的用户名和密码后，提示"用户名或密码错误"。

**根本原因**: **密码加密方法不匹配**

- **密码存储**: 使用 SHA256 哈希（`src/utils/auth.ts`）
- **密码验证**: Web 登录路由使用 `bcryptjs`（`src/routes/admin.routes.ts:48-49`）

```typescript
// src/routes/admin.routes.ts 中的问题代码
const { compare } = await import('bcryptjs');
const isPasswordValid = await compare(password, user.password); // ❌ 错误：使用 bcrypt 比较 SHA256 哈希
```

**解决方案**:

#### 方案 1: 使用 API 登录接口（推荐）

直接使用 API 登录接口，它使用正确的密码验证方法：

```bash
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"REDACTED_ADMIN_PASS"}'
```

或者使用 JavaScript:

```javascript
fetch('http://localhost:3000/api/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    username: 'admin',
    password: 'REDACTED_ADMIN_PASS'
  })
})
.then(res => res.json())
.then(data => console.log(data));
```

#### 方案 2: 修复 Web 登录路由（需要修改代码）

修改 `src/routes/admin.routes.ts` 第 48-49 行：

```typescript
// 替换
const { compare } = await import('bcryptjs');
const isPasswordValid = await compare(password, user.password);

// 为
const { comparePassword } = await import('../utils/auth.js');
const isPasswordValid = await comparePassword(password, user.password);
```

### 问题 2: 管理员账号不存在

**症状**: 启动系统后无法登录，提示"用户名或密码错误"。

**排查步骤**:

1. **检查数据库中是否存在管理员账号**:

```bash
# SQLite
sqlite3 data/database.sqlite "SELECT * FROM users WHERE role='admin';"

# MySQL
mysql -u root -p -e "SELECT * FROM playwright_user_sys.users WHERE role='admin';"
```

2. **查看启动日志**: 管理员账号创建时会输出日志：
```
✅ 管理员账号 admin 创建成功
```

3. **检查环境变量**: 确认 `.env` 文件中的配置：
```bash
ADMIN_USERNAME=admin
ADMIN_PASSWORD=REDACTED_ADMIN_PASS
```

**解决方案**:

如果管理员账号不存在，可以手动创建：

#### 方法 1: 使用创建脚本

```bash
pnpm migrate
```

#### 方法 2: 直接插入数据库

**SQLite**:
```bash
sqlite3 data/database.sqlite "INSERT INTO users (username, password, role, status, credits, created_at, updated_at) VALUES ('admin', '240be518fabd2724ddb6f04eeb1da5967448d7e831c08c8fa822809f74c720a9', 'admin', 'active', 9999999, datetime('now'), datetime('now'));"
```

**MySQL**:
```sql
INSERT INTO users (username, password, role, status, credits, created_at, updated_at)
VALUES ('admin', '240be518fabd2724ddb6f04eeb1da5967448d7e831c08c8fa822809f74c720a9', 'admin', 'active', 9999999, NOW(), NOW());
```

### 问题 3: 修改环境变量密码后仍无法登录

**原因**: 系统仅在**首次启动且管理员不存在时**才创建管理员账号。如果管理员已存在，修改环境变量不会自动更新数据库中的密码。

**解决方案**: 参见[密码重置方法](#密码重置方法)章节。

### 问题 4: 数据库连接失败

**症状**: 启动时提示数据库连接错误。

**排查步骤**:

1. **检查数据库类型**:
```bash
# 查看 .env 文件
DB_TYPE=sqlite  # 或 mysql
```

2. **SQLite 用户**: 检查数据库文件是否存在：
```bash
ls -la data/database.sqlite
```

3. **MySQL 用户**: 测试数据库连接：
```bash
mysql -h your-db-host -u root -p
```

**解决方案**:

确保数据库配置正确，并运行迁移：
```bash
pnpm migrate
```

## 密码管理方法

### 生成密码哈希

如果需要手动创建用户或重置密码，可以使用以下方法生成 SHA256 哈希：

#### 方法 1: Node.js

```javascript
const crypto = require('crypto');
const password = 'your-password';
const hash = crypto.createHash('sha256').update(password).digest('hex');
console.log(hash);
```

#### 方法 2: 命令行

```bash
node -e "const crypto = require('crypto'); console.log(crypto.createHash('sha256').update('your-password').digest('hex'));"
```

#### 方法 3: 使用在线工具

访问 SHA256 在线哈希工具（如 https://emn178.github.io/online-tools/sha256.html）

### 密码重置方法

#### 方法 1: 通过 API 更新密码

需要管理员 Token：

```bash
curl -X PUT http://localhost:3000/api/users/1 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -d '{"password": "new-password"}'
```

#### 方法 2: 直接更新数据库

**SQLite**:
```bash
# 生成新密码的哈希
NEW_HASH=$(node -e "console.log(require('crypto').createHash('sha256').update('new-password').digest('hex'))")

# 更新数据库
sqlite3 data/database.sqlite "UPDATE users SET password='$NEW_HASH' WHERE username='admin';"
```

**MySQL**:
```sql
-- 首先生成密码哈希（使用 Node.js）
-- 然后执行
UPDATE users SET password='240be518fabd2724ddb6f04eeb1da5967448d7e831c08c8fa822809f74c720a9' WHERE username='admin';
```

#### 方法 3: 删除并重新创建管理员

```bash
# SQLite
sqlite3 data/database.sqlite "DELETE FROM users WHERE username='admin';"

# 然后重启服务，系统会自动创建管理员
pnpm dev
```

### 手动创建用户

#### 方法 1: 使用 API

需要管理员权限：

```bash
curl -X POST http://localhost:3000/api/users \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -d '{
    "username": "newuser",
    "password": "password123",
    "email": "user@example.com",
    "role": "user",
    "credits": 100
  }'
```

#### 方法 2: 使用测试脚本

```bash
pnpm create-test-user
```

这会创建一个测试用户：
- 用户名: `test_user`
- 密码: `test_password`
- 点数: 100

#### 方法 3: 直接插入数据库

```bash
# 生成密码哈希
PASSWORD_HASH=$(node -e "console.log(require('crypto').createHash('sha256').update('password123').digest('hex'))")

# 插入用户
sqlite3 data/database.sqlite "INSERT INTO users (username, password, role, status, credits, created_at, updated_at) VALUES ('newuser', '$PASSWORD_HASH', 'user', 'active', 100, datetime('now'), datetime('now'));"
```

## 常见问题解决方案

### Q1: 如何查看当前数据库中的所有用户？

**SQLite**:
```bash
sqlite3 data/database.sqlite "SELECT id, username, role, status, credits FROM users;"
```

**MySQL**:
```bash
mysql -u root -p -e "SELECT id, username, role, status, credits FROM playwright_user_sys.users;"
```

### Q2: 如何验证密码是否正确？

检查密码哈希：

```bash
# 生成密码哈希进行比对
node -e "console.log(require('crypto').createHash('sha256').update('REDACTED_ADMIN_PASS').digest('hex'))"

# 应该输出: 240be518fabd2724ddb6f04eeb1da5967448d7e831c08c8fa822809f74c720a9
```

然后与数据库中的密码哈希比对：

```bash
sqlite3 data/database.sqlite "SELECT username, password FROM users WHERE username='admin';"
```

### Q3: 为什么 Web 登录和 API 登录行为不一致？

这是由于代码实现不一致导致的：

- **API 登录** (`/api/auth/login`): 使用 `comparePassword()` 函数，正确实现 SHA256 比较
- **Web 登录** (`/admin/login`): 错误地使用 `bcryptjs.compare()` 尝试比较 SHA256 哈希

**解决方案**: 参见[问题 1](#问题-1-无法登录到-web-管理后台)的解决方案。

### Q4: 如何完全重置系统？

删除数据库文件并重新启动：

```bash
# SQLite
rm data/database.sqlite
pnpm dev

# MySQL
mysql -u root -p -e "DROP DATABASE playwright_user_sys; CREATE DATABASE playwright_user_sys;"
pnpm dev
```

### Q5: 启动时如何确认管理员账号是否创建成功？

查看启动日志，应该看到：

```
🔄 开始数据库迁移...
✅ 用户表创建成功
✅ 实例机器表创建成功
✅ 会话表创建成功
✅ 操作日志表创建成功
✅ 请求日志表创建成功
✅ Webhook 事件表创建成功
✅ 管理员账号 admin 创建成功
✅ 数据库迁移完成
```

如果没有看到"管理员账号 admin 创建成功"，说明管理员已存在。

### Q6: 如何创建多个管理员账号？

使用 API 创建：

```bash
curl -X POST http://localhost:3000/api/users \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -d '{
    "username": "admin2",
    "password": "password123",
    "role": "admin",
    "credits": 9999999
  }'
```

或直接插入数据库：

```bash
sqlite3 data/database.sqlite "INSERT INTO users (username, password, role, status, credits, created_at, updated_at) VALUES ('admin2', '240be518fabd2724ddb6f04eeb1da5967448d7e831c08c8fa822809f74c720a9', 'admin', 'active', 9999999, datetime('now'), datetime('now'));"
```

### Q7: JWT Token 有效期是多久？

默认配置：1 天（在 `.env` 中配置）

```bash
JWT_EXPIRES_IN=1d
```

可以修改为：
- `1h` - 1 小时
- `7d` - 7 天
- `30d` - 30 天

### Q8: 如何查看当前 JWT 配置？

查看 `.env` 文件：

```bash
JWT_SECRET=your-secret-key-change-in-production
JWT_EXPIRES_IN=1d
```

**⚠️ 安全提示**: 生产环境请务必修改 `JWT_SECRET` 为强随机字符串。

## 技术细节

### 密码加密算法对比

| 算法 | 使用位置 | 安全性 | 速度 |
|------|---------|--------|------|
| SHA256 | `src/utils/auth.ts` | 中等 | 快 |
| bcrypt | `src/routes/admin.routes.ts`（错误使用） | 高 | 慢 |

**当前状态**: 系统使用 SHA256 存储密码，这是出于性能考虑。对于高安全要求的场景，建议迁移到 bcrypt。

### 数据库表结构

```sql
CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  username VARCHAR(255) NOT NULL UNIQUE,
  password VARCHAR(255) NOT NULL,
  email VARCHAR(255),
  role VARCHAR(50) NOT NULL DEFAULT 'user',
  status VARCHAR(50) NOT NULL DEFAULT 'active',
  credits INTEGER NOT NULL DEFAULT 0,
  api_key VARCHAR(255) UNIQUE,
  webhook_url VARCHAR(255),
  created_at DATETIME,
  updated_at DATETIME
);
```

## 总结

### 核心要点

1. **默认管理员**: 用户名 `admin`，密码 `REDACTED_ADMIN_PASS`
2. **密码加密**: 使用 SHA256 哈希算法
3. **初始化**: 仅在首次启动且管理员不存在时创建
4. **已知问题**: Web 登录使用 bcrypt 验证 SHA256 哈希，导致无法登录
5. **推荐方案**: 使用 API 登录接口 `/api/auth/login`

### 快速问题解决清单

| 问题 | 解决方案 |
|------|---------|
| 无法登录 Web 管理后台 | 使用 API 接口登录或修复代码 |
| 管理员账号不存在 | 运行 `pnpm migrate` |
| 忘记管理员密码 | 重置密码为 `REDACTED_ADMIN_PASS` |
| 修改环境变量后密码不变 | 手动更新数据库中的密码 |
| 密码哈希不匹配 | 确保使用 SHA256 哈希 |

### 安全建议

1. 修改默认管理员密码
2. 修改 `JWT_SECRET` 为强随机字符串
3. 在生产环境使用 HTTPS
4. 定期备份用户数据库
5. 考虑升级到 bcrypt 进行密码加密
