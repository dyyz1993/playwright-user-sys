# 登录问题快速排查指南

本指南提供登录问题的快速诊断和解决方案。

## 诊断检查清单

### 第一步：确认管理员账号是否存在

```bash
# SQLite
sqlite3 data/database.sqlite "SELECT id, username, role, status FROM users WHERE role='admin';"

# MySQL
mysql -u root -p -e "SELECT id, username, role, status FROM playwright_user_sys.users WHERE role='admin';"
```

**期望输出**:
```
1|admin|admin|active
```

**如果没有输出**: 管理员账号不存在 → [跳转到解决方案 A](#解决方案-a管理员账号不存在)

**如果有输出**: 继续下一步检查

---

### 第二步：验证密码哈希

```bash
# 查看数据库中的密码哈希
sqlite3 data/database.sqlite "SELECT substr(password, 1, 20) as pwd FROM users WHERE username='admin';"

# 生成正确的哈希进行对比
node -e "console.log('正确的哈希:', require('crypto').createHash('sha256').update('REDACTED_ADMIN_PASS').digest('hex').substring(0, 20));"
```

**期望输出**:
```
240be518fabd2724ddb6
```

**如果不匹配**: 密码哈希错误 → [跳转到解决方案 B](#解决方案-b密码哈希错误)

---

### 第三步：检查登录接口

**测试 Web 登录**:
```bash
curl -X POST http://localhost:3000/admin/login \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=admin&password=REDACTED_ADMIN_PASS" \
  -v
```

**测试 API 登录**:
```bash
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"REDACTED_ADMIN_PASS"}' \
  -v
```

**API 登录成功**: 说明密码正确，Web 登录有 bug → [跳转到解决方案 C](#解决方案-cweb-登录密码验证-bug)

**两者都失败**: 继续下一步

---

### 第四步：检查环境变量

```bash
# 查看当前环境变量
cat .env | grep ADMIN
```

**期望输出**:
```
ADMIN_USERNAME=admin
ADMIN_PASSWORD=REDACTED_ADMIN_PASS
```

**如果不匹配**: 环境变量配置错误 → [跳转到解决方案 D](#解决方案-d环境变量配置错误)

---

## 解决方案

### 解决方案 A：管理员账号不存在

**方法 1：运行迁移脚本**
```bash
pnpm migrate
```

**方法 2：直接插入数据库**
```bash
sqlite3 data/database.sqlite "INSERT INTO users (username, password, role, status, credits, created_at, updated_at) VALUES ('admin', '240be518fabd2724ddb6f04eeb1da5967448d7e831c08c8fa822809f74c720a9', 'admin', 'active', 9999999, datetime('now'), datetime('now'));"
```

**方法 3：删除数据库重建**
```bash
rm data/database.sqlite && pnpm dev
```

---

### 解决方案 B：密码哈希错误

**重置管理员密码**:
```bash
# 生成新密码哈希
NEW_HASH=$(node -e "console.log(require('crypto').createHash('sha256').update('REDACTED_ADMIN_PASS').digest('hex'))")

# 更新数据库
sqlite3 data/database.sqlite "UPDATE users SET password='$NEW_HASH' WHERE username='admin';"
```

---

### 解决方案 C：Web 登录密码验证 Bug

**这是已知问题**：Web 登录使用 `bcryptjs` 验证 SHA256 哈希，导致验证失败。

**临时方案：使用 API 登录**
```bash
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"REDACTED_ADMIN_PASS"}'
```

返回的 token 可以用于后续请求：
```bash
# 保存 token
export TOKEN="返回的token"

# 使用 token 访问受保护的接口
curl http://localhost:3000/api/auth/me \
  -H "Authorization: Bearer $TOKEN"
```

**永久方案：修复代码**

编辑 `src/routes/admin.routes.ts` 第 48-49 行：

```typescript
// 修改前
const { compare } = await import('bcryptjs');
const isPasswordValid = await compare(password, user.password);

// 修改后
const { comparePassword } = await import('../utils/auth.js');
const isPasswordValid = await comparePassword(password, user.password);
```

然后重启服务。

## 根本原因分析

### 主要问题：密码加密方法不匹配

系统存在两套密码验证逻辑：

1. **API 登录** (`src/controllers/auth.controller.ts`):
   - 使用 `comparePassword()` 函数
   - 正确实现 SHA256 比较
   - ✅ 工作正常

2. **Web 登录** (`src/routes/admin.routes.ts`):
   - 使用 `bcryptjs.compare()` 函数
   - 错误地尝试用 bcrypt 验证 SHA256 哈希
   - ❌ 无法登录

### 代码位置

**问题代码**: `src/routes/admin.routes.ts:48-49`
```typescript
const { compare } = await import('bcryptjs');
const isPasswordValid = await compare(password, user.password);
```

**正确代码**: `src/controllers/auth.controller.ts:27`
```typescript
const isValid = await comparePassword(password, user.password);
```

## 快速修复方案

### 一键修复脚本

创建文件 `scripts/fix-login.sh`:

```bash
#!/bin/bash

echo "正在修复登录问题..."

# 检查管理员是否存在
ADMIN_EXISTS=$(sqlite3 data/database.sqlite "SELECT COUNT(*) FROM users WHERE username='admin';")

if [ "$ADMIN_EXISTS" -eq "0" ]; then
    echo "管理员不存在，正在创建..."
    sqlite3 data/database.sqlite "INSERT INTO users (username, password, role, status, credits, created_at, updated_at) VALUES ('admin', '240be518fabd2724ddb6f04eeb1da5967448d7e831c08c8fa822809f74c720a9', 'admin', 'active', 9999999, datetime('now'), datetime('now'));"
    echo "管理员创建成功"
else
    echo "管理员已存在"
fi

# 测试登录
echo "测试登录..."
RESPONSE=$(curl -s -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"REDACTED_ADMIN_PASS"}')

echo "$RESPONSE" | grep -q "token"

if [ $? -eq 0 ]; then
    echo "✅ 登录测试成功"
else
    echo "❌ 登录测试失败"
fi

echo "完成！"
```

使用方法：
```bash
chmod +x scripts/fix-login.sh
./scripts/fix-login.sh
```
