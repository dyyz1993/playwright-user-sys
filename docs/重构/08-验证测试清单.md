## 1. 测试标准

### 1.1 测试类型说明

| 测试类型 | 说明 | 执行时机 |
|----------|------|----------|
| 基线测试 | 重构前的功能状态记录 | 每次重构前 |
| 验证脚本 | 自动化验证脚本测试 | 每次重构后 |
| 单元测试 | Vitest 单元测试 | 每次重构后 |
| API 测试 | API 功能测试 | 每次重构后 |
| 集成测试 | 完整功能集成测试 | 所有步骤完成后 |

### 1.2 测试执行标准

```
┌─────────────────────────────────────────────────────────────────┐
│                    标准重构测试流程                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 重构前基线测试                                               │
│     └── 记录当前功能状态                                        │
│                                                                 │
│  2. 执行重构操作                                                │
│     └── 按步骤文档执行                                          │
│                                                                 │
│  3. 验证脚本测试                                                │
│     └── node tests/verify-step{N}.js                           │
│                                                                 │
│  4. 功能验证测试                                                │
│     ├── TypeScript 编译: pnpm build                             │
│     ├── 单元测试: pnpm test:unit                                │
│     ├── API 测试: pnpm test:api                                 │
│     └── 启动验证: pnpm dev:server / pnpm dev:machine            │
│                                                                 │
│  5. 结果处理                                                    │
│     ├── 全部通过 → Git 提交，继续下一步                          │
│     └── 有失败 → 回滚，修复问题后重新执行                        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 9. 故障排查指南

### 9.1 常见测试失败

| 失败类型 | 可能原因 | 排查方法 |
|----------|----------|----------|
| 模块导入失败 | 路径映射未配置 | 检查 tsconfig.json |
| 编译错误 | 类型不匹配或路径错误 | 检查导入路径 |
| 启动失败 | 端口占用或配置错误 | 检查端口和配置文件 |
| API 测试失败 | 服务未启动或数据库问题 | 检查服务状态和数据库 |

### 9.2 调试命令

```bash
# 检查端口占用
lsof -i :3000
lsof -i :50051

# 检查 TypeScript 编译详情
pnpm build --pretty

# 查看服务日志
pnpm dev:server

# 清理并重新安装
rm -rf node_modules dist
pnpm install
pnpm build
```
