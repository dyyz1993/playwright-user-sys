Key Findings

  • Slider drag works via WS events: BrowserViewer.instance.send() successfully forwards mouse events (mousedown→mousemove→mouseup) to the remote browser. The slider verification completed successfully.
  • Sort drag works with proper coordinates: Required scrolling the remote browser to make sort items visible, then mousedown on sort item + progressive mousemove with dy>40px between swaps.
  • Mobile viewer has rendering issue: At 375×812 viewport, the browser viewer shows a dark/empty content area despite WS being connected (15 FPS). Touch events were sent but visual verification was not possible.
  • File upload is a known limitation: The remote browser viewer cannot capture OS-level file picker dialogs. Clicking the upload area triggers the dialog on the remote machine, but it's not visible in the viewer.
  • Standalone viewer works well: The browser-viewer page at /browser-viewer/index.html works independently and displays remote browser content correctly.
  • Remote browser viewport is 1280×800: All coordinate calculations must map to this resolution. Content is centered in a 600px max-width container (x≈340 to x≈940).
  • 502 errors on first navigation attempt: The first session got 502 errors when navigating to slider test page. Creating a new session resolved the issue.
