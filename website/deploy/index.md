# 部署概览

Playwright User Sys 支持两种部署方式。根据你的场景选择最合适的方案。

## 方案对比

| 维度 | Docker 部署（推荐） | 裸机部署 |
|------|-------------------|---------|
| 适用场景 | 生产环境、多机器集群 | 单机试用、资源受限、已有 Node 环境 |
| 系统依赖 | 无需手动安装 | 需安装 libnss3/libatk 等 20+ 个库 |
| 部署速度 | 拉取镜像即用 | 一键脚本约 5 分钟 |
| 升级方式 | `docker compose pull && up -d` | `git pull && pnpm build` |
| 浏览器管理 | 宿主机 Chrome 只读挂载 | 系统安装的 Chrome |
| 进程管理 | Docker Compose 自动重启 | systemd 托管 |
| 首次磁盘占用 | ~2.5-3 GB（含基础镜像） | ~1 GB |

选择合适的方案：

- 👉 [Docker 部署 →](./docker.md)
- 👉 [手动部署（裸机） →](./manual.md)
- 👉 [环境变量参考 →](./environment-variables.md)

## 磁盘占用说明

### 首次部署

- **Docker 方案**：~2.5-3 GB（含 node:22 基础镜像、prod 依赖、X11 库、中文字体）
- **裸机方案**：~1 GB（代码+依赖 ~450MB + Chrome ~300MB + 系统库 ~200MB）

### 运行时数据增长

系统已内置自动清理机制，无需手动维护：

| 数据类型 | 清理策略 | 默认保留 |
|---------|---------|---------|
| 截图 `data/screenshots/` | 自动删除过期文件 | 7 天 |
| 会话 user-data | 正常关闭即删；崩溃残留 24h 后自动清 | 24 小时 |
| 共享 user-data | 自动删除长期未用的 | 30 天 |
| 日志 `logs/*.log` | 每日轮转时删除过期 | 30 天 |
| 临时文件 | 自动删除过期 | 24 小时 |
| 上传文件 | 自动删除过期 | 7 天 |

## 端口规划

| 服务 | 默认端口 | 环境变量 | 说明 |
|------|---------|---------|------|
| Manager HTTP | 3000 | `PORT` | REST API + Web 界面 |
| Manager gRPC | 50051 | `GRPC_PORT` | Manager ↔ Machine 通信 |
| Machine gRPC | 50052 | `MACHINE_GRPC_PORT` | 每台 Machine 递增（50053, 50054...） |
| Machine WS 代理 | 8082 | `PROXY_PORT` | 浏览器远程控制，每台递增（8083, 8084...） |
| Machine 健康检查 | 9100 | `MACHINE_HEALTH_PORT` | HTTP 健康端点 |

::: tip 多机器部署
每台 Machine 需要不同的 gRPC 端口和 WebSocket 代理端口。建议使用 50052/8082 开始依次递增分配。
:::
