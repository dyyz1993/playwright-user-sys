## 组件说明

### Management Server (管理服务器)

核心后端服务，基于 **Fastify** 框架构建，提供：

- **用户管理**：注册、登录、权限控制
- **会话管理**：浏览器会话的创建、分配、释放
- **积分计费**：按使用量自动扣费
- **机器管理**：机器节点注册、健康检查、负载均衡
- **文件管理**：文件上传和分发
- **API Playground**：内置在线 API 测试界面

### Machine Service (机器服务)

运行 Playwright 浏览器实例的工作节点，支持分布式部署：

- **浏览器实例管理**：创建和销毁浏览器实例
- **gRPC 服务**：与管理服务器通信
- **WebSocket 代理**：实现 CDP 直连
- **健康上报**：定期上报状态

### Client SDK (客户端 SDK)

客户端工具库，封装了与管理服务器交互的完整流程。

## 通信方式

| 方式 | 用途 | 协议 |
|------|------|------|
| REST API | 管理操作（创建会话、用户管理） | HTTP/JSON |
| WebSocket | 浏览器 CDP 代理连接 | ws:// |
| gRPC | 服务器与机器节点通信 | HTTP/2 + Protobuf |

## 数据流

```
客户端请求创建会话
  │
  ▼
Management Server 验证身份和积分
  │
  ▼
Management Server 分配机器节点
  │
  ▼
Machine Service 启动 Playwright 浏览器
  │
  ▼
Management Server 返回 WebSocket 连接地址
  │
  ▼
客户端通过 WebSocket 直连浏览器 CDP
  │
  ▼
会话结束 → 释放资源 → 扣除积分
```

## 数据库

| 环境 | 数据库 |
|------|--------|
| 开发环境 | SQLite (默认) |
| 生产环境 | MySQL 8.0+ |

### 核心表

- **users** - 用户账号、密码、角色、积分余额
- **sessions** - 浏览器会话记录
- **machines** - 机器节点注册信息
- **credit_history** - 积分变动记录
- **operation_logs** - 操作审计日志
